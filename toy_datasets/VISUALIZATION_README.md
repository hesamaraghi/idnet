# Cached Dataset Visualization Guide

Complete guide for `visualize_cached_dataset.py` - a comprehensive tool for visualizing event datasets with optical flow.

## Quick Start

```bash
# List all cached datasets
python visualize_cached_dataset.py --list

# Full visualization of a dataset
python visualize_cached_dataset.py --index 0

# Simple flow arrow visualization
python visualize_cached_dataset.py --index 0 --draw_arrows --arrow_time_start 500 --arrow_num_events 100
```

## Overview

This script provides comprehensive visualization capabilities for cached event datasets generated by `knn_mlp.py`. It supports:

- ✅ Event scatter plots and temporal distributions
- ✅ Optical flow analysis with multiple visualizations
- ✅ Event frame animations (GIF/MP4)
- ✅ Temporal slices with flow arrows
- ✅ Simple notebook-style quiver plots
- ✅ Detailed flow statistics

**Input**: Cached `.pt` files in `dataset_cache/` directory  
**Output**: PNG images, GIF animations, and text statistics

---

## Command-Line Options

### Dataset Selection

```bash
--list                    # List all cached datasets with info
--index N                 # Select dataset by index (from --list)
--hash PREFIX             # Select dataset by hash prefix
--cache_dir PATH          # Cache directory (default: dataset_cache)
```

**Examples:**
```bash
python visualize_cached_dataset.py --list
python visualize_cached_dataset.py --index 3
python visualize_cached_dataset.py --hash aa895999
```

### Output Configuration

```bash
--output_dir PATH         # Output directory (default: visualizations)
--show                    # Display plots interactively (default: save only)
```

### Full Visualization Options

```bash
--num_bins N              # Number of time bins for animation (default: 50)
--img_size H W            # Image dimensions in pixels (default: 256 256)
--time_window T1 T2       # Visualize only time range [T1, T2]
--no_animation            # Skip animation generation (faster)
--use_generator           # Use DatasetGenerator's high-quality animations
--config_path PATH        # Config file for generator animations
```

### Arrow Drawing Mode (Simple Quiver Plot)

```bash
--draw_arrows             # Enable arrow drawing mode
--arrow_time_start T      # Start timestamp (required with --draw_arrows)
--arrow_num_events N      # Number of consecutive events (default: 100)
--arrow_scale SCALE       # Arrow length multiplier (default: 20)
```

### Shape Animation

```bash
--create_shape_animation  # Create shape movement animation
--config_path PATH        # Dataset config file (required)
```

## Visualization Modes

### Mode 1: Full Visualization (Default)

**Command:**
```bash
python visualize_cached_dataset.py --index 0
```

**Generates:**
- Event scatter plots (4 panels: spatial, temporal, X-T, Y-T)
- Sample event frames (6 snapshots)
- Event animation (GIF/MP4)
- Optical flow analysis (7-panel comprehensive view)
- Temporal slices with flow arrows (6 time windows)
- Flow statistics text file

**Use cases:**
- Complete dataset analysis
- Comparing synthetic vs. v2e-generated events
- Understanding flow patterns throughout sequence
- Publication-quality figures

**Typical runtime:** 30-120 seconds depending on dataset size

---

### Mode 2: Arrow Drawing (Simple & Fast)

**Command:**
```bash
python visualize_cached_dataset.py --index 0 \
    --draw_arrows \
    --arrow_time_start 500 \
    --arrow_num_events 100 \
    --arrow_scale 20
```

**Generates:**
- Single PNG with flow arrows overlaid on events
- Red/blue color coding by polarity
- Large, visible arrows for detailed inspection

**Use cases:**
- Quick flow verification
- Notebook-style visualization
- Inspecting specific time moments
- Creating presentation slides

**Typical runtime:** 2-5 seconds

**Parameters explained:**
- `--arrow_time_start`: Timestamp to start from (e.g., 500)
- `--arrow_num_events`: Exactly how many events to show (e.g., 100)
- `--arrow_scale`: Arrow length multiplier (typical range: 10-30)
  - Small scale (5-10): Dense arrows, more overlap
  - Medium scale (15-25): Good balance
  - Large scale (30+): Very prominent arrows

---

### Mode 3: Shape Animation

**Command:**
```bash
python visualize_cached_dataset.py \
    --create_shape_animation \
    --config_path configs/star8_config.yaml
```

**Generates:**
- High-quality shape movement animation
- With or without textures based on config

**Use cases:**
- Understanding shape trajectories
- Debugging motion patterns
- Creating ground truth animations

## Advanced Features

### 1. Flow Colorwheel Visualization

The optical flow analysis includes a colorwheel legend:
- **Hue (color)**: Flow direction (red=right, yellow=down, cyan=left, blue=up)
- **Brightness**: Flow magnitude (darker=slower, brighter=faster)

### 2. Automatic Downsampling

For large datasets, the script automatically downsamples for performance:
- Event scatter plots: max 100K events
- Flow quiver plots: max 5K arrows
- Temporal slices: max 3K events per slice, 500 arrows

This ensures fast rendering without losing visual patterns.

### 3. Temporal Slices

The full visualization automatically creates 6 temporal slices:
- Evenly distributed throughout the sequence
- Each slice shows 5% of total duration
- Arrows scaled consistently for comparison
- Automatic handling of variable event density

### 4. Multiple Animation Formats

When creating animations:
- **GIF**: Always generated, works everywhere
- **MP4**: Generated if ffmpeg is available (higher quality, smaller file)

### 5. Interactive Display

Use `--show` to display plots interactively:
```bash
python visualize_cached_dataset.py --index 0 --show
```

Useful for:
- Zooming into specific regions
- Adjusting display settings
- Quick inspection before saving

## Tips and Troubleshooting

### Choosing the Right Mode

| Goal | Mode | Command |
|------|------|---------|
| Complete analysis | Full | `--index 0` |
| Quick flow check | Arrows | `--draw_arrows --arrow_time_start X` |
| Specific time range | Full + window | `--time_window T1 T2` |
| Fast iteration | Arrows + no anim | `--draw_arrows --no_animation` |

### Arrow Scale Guidelines

**Rule of thumb:** Arrow scale = 20 / (typical flow magnitude)

For typical flow magnitudes:
- 0.3-0.5 pixels: use scale 15-25
- 0.5-1.0 pixels: use scale 10-20
- 1.0+ pixels: use scale 5-15

**How to check flow magnitude:**
1. Run full visualization first
2. Check `*_flow_stats.txt` for mean magnitude
3. Adjust arrow scale accordingly

### Event Count Selection

**Fixed event count vs. time window:**
- Use `--arrow_num_events` when event density varies
- Use `--time_window` when you need exact time range
- Fixed event count gives consistent visualization density

**Typical values:**
- 50 events: Sparse, good for detailed arrow inspection
- 100 events: Standard, balanced view
- 200-500 events: Dense, good for overall pattern
- 1000+ events: Very dense, may need larger arrow scale

### Performance Optimization

**For large datasets (>1M events):**
```bash
# Fast visualization without animation
python visualize_cached_dataset.py --index 0 --no_animation

# Arrow mode is always fast
python visualize_cached_dataset.py --index 0 --draw_arrows --arrow_time_start 500
```

**For multiple visualizations:**
```bash
# Use arrow mode for iteration
python visualize_cached_dataset.py --index 0 --draw_arrows --arrow_time_start 500
python visualize_cached_dataset.py --index 0 --draw_arrows --arrow_time_start 1000

# Full visualization once when satisfied
python visualize_cached_dataset.py --index 0
```

### Common Issues

**Issue:** "No events at or after timestamp X"
- **Solution:** Check dataset time range with `--list`, adjust `--arrow_time_start`

**Issue:** "Arrows too small to see"
- **Solution:** Increase `--arrow_scale` (try 30-50)

**Issue:** "Arrows too cluttered"
- **Solution:** 
  - Reduce `--arrow_num_events` (try 50)
  - Reduce `--arrow_scale` (try 10-15)

**Issue:** "Animation takes too long"
- **Solution:** Use `--no_animation` or reduce `--num_bins`

**Issue:** "Multiple datasets match hash"
- **Solution:** Provide more specific hash prefix (first 12+ characters)

### Understanding Output

**Event scatter plot panels:**
1. **Top-left:** Spatial distribution (where events occur)
2. **Top-right:** Temporal histogram (when events occur)
3. **Bottom-left:** X-T plot (horizontal motion over time)
4. **Bottom-right:** Y-T plot (vertical motion over time)

**Flow analysis panels:**
1. **Magnitude histogram:** Distribution of flow speeds
2. **Direction polar plot:** Which directions dominate
3. **X vs Y scatter:** Flow vector distribution
4. **Quiver plot:** Arrow field showing motion
5. **Colorwheel legend:** How to interpret colors
6. **Flow colormap:** Dense visualization of flow
7. **Magnitude heatmap:** Where flow is strongest

## Summary

**Two main modes:**

1. **Full Visualization** (`--index N`): Complete analysis with all plots
   - Best for: Publication, comprehensive analysis
   - Runtime: 30-120 seconds
   - Outputs: 7 files including animations

2. **Arrow Drawing** (`--draw_arrows`): Fast, focused flow inspection
   - Best for: Quick checks, iteration, specific moments
   - Runtime: 2-5 seconds
   - Outputs: 1 PNG file

**Key parameters:**
- `--arrow_time_start`: Where to start
- `--arrow_num_events`: How many events (50-500 typical)
- `--arrow_scale`: Arrow size (15-25 typical)

**Pro tip:** Start with arrow mode for exploration, then use full mode for final analysis.
